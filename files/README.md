# Офлайн-файлы

Сюда кладутся пакеты, скачанные вручную на машине с интернетом, если их нет в зеркале.
Роли находят файлы автоматически; в git они не попадают (см. `.gitignore`).

| Каталог | Что положить | Кто использует |
|---|---|---|
| `rpms/` | `patroni-*.rpm`, `patroni-etcd-*.rpm` и их зависимости из PGDG `common` | роль `patroni` |
| `etcd/` | `etcd-vX.Y.Z-linux-amd64.tar.gz` (релиз с GitHub) | роль `etcd` |

Когда пакеты появятся в зеркале, удалите файлы отсюда — роли вернутся к установке из репозиториев.
